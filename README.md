# args-and-kwargs
**Python *args and kwargs: Learn how to pass multiple positional and keyword arguments to Python functions using *args and **kwargs.

<>*args and **kwargs in Python
1. args
- Used to pass multiple positional arguments to a function.
- Stores all arguments in a tuple.
- Useful when the number of arguments is unknown.

2. kwargs
- Used to pass multiple keyword arguments to a function.
- Stores all arguments in a dictionary.
